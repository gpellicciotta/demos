# Demos &amp; Experiments

A collection of lightweight client-side applications, Web API experiments, and interactive developer prototypes.

Live showcase available at: **[https://apps.pellicciotta.com/demos](https://apps.pellicciotta.com/demos)**

## Available Demos

- **Voice to Text Transcriber** ([`web-speech-api-voice-to-text-demo.html`](web-speech-api-voice-to-text-demo.html))  
  Multi-engine voice transcription supporting the browser-native `SpeechRecognition` Web Speech API and Groq's Free Dedicated Whisper API (`whisper-large-v3-turbo` and `whisper-large-v3`) with multi-select tabbed comparison, automatic language detection, and clipboard export.
